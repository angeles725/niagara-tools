### Added — `nre-tool.sh list`, `palette` and `recompile`: the other nre build-time tools from the loop (issue #851)

- `toolbelt/nre-tool.sh list` names the supported tools with a purpose; an unknown tool is exit 3 with that list.
- `palette <niagara_home> <moduleDir>` runs `PaletteGenerator`, which replaces `<moduleDir>/module.palette`:
  - it runs only on a module part directory (`module-include.xml` beside `src/`) and needs `bin/nre.exe`;
  - it prints the file it will write first, so the change shows in `git diff`.
- `recompile <niagara_home> <dir|bog> [-alias:<a>] [-tsaUrl:<u>]` runs `RecompileTool`:
  - a `-password...` argument is refused; nre prompts on the terminal, so the password never reaches argv;
  - `-alias:` and `-tsaUrl:` pass through.
- nre's exit code is the exit. Both classes exit 0 after a failure they print, so `palette` reads
  "Failed to generate palette" and `recompile` an `ERROR` line or no `--- Processed <file>!` line as exit 1.
- `deps` is unchanged.
