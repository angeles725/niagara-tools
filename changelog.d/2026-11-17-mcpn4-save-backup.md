### Added — mcp-n4: n4_save_station backup=true zips the station directory (O5)
- With `backup: true` and a `--station-home`, after the save the station directory is zipped to `<state-dir>/backups/<station>-<UTC time>.zip` (0600, never overwritten) without what the station's BackupService excludes (`*.hdb`, `*.adb`, `*.lock`, `*backup*`, `console.*`, `config.bog.b*`, `config_backup*`; the `history`, `alarm`, `webFileCache` directories). The reply's `backup` lists path, files, bytes, sha256 and the excluded entries, or `{error}`.
- Without a station home the dry run refuses the backup. A Fox/platform `.dist` backup for remote stations is a later campaign.
