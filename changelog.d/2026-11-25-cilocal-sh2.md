### Changed

- `scripts/ci-local.sh --changed` runs `bats tests/shell-hygiene.bats` (SH1: no unquoted `&` or `$` in a
  pattern-substitution replacement) as a hard gate when a `tests/*.bats` or a `tests/lib/**` file changes, as it does
  for the other bats lints. A change to a bats file or helper could break it in CI only: the lints ran
  `lint-bats-errexit` and `lint-bats-heredoc`, not this suite. The row is in `go/internal/cisteps/gates.go`
  (`bats tests/shell-hygiene.bats`); a tree with no `tests/shell-hygiene.bats` prints a skip line. Unit test
  `TestChangedBatsFilesRunTheShellHygieneGate` and bats `CG11` pin it. Issue #1052.
