### Added

- `n4-probe` (#986 Δ34): the kit's Go live probe of a station HTTP API. `n4-probe stall --url URL` GETs a URL and
  prints the error counts, min/p50/p90/p99/max latency and a histogram; `n4-probe pulse --press URL --observe URL
  --field PATH` presses a point and prints each change of the watched JSON fields (ms since the press) and the
  release time (exit 3 when not released in time). One request in flight, 4 Hz cap (`--allow-rate-above-4` lifts
  it), `--duration` default 30s (max 10m), credentials `N4_PROBE_USER`/`N4_PROBE_PASSWORD` only from `--env-file`.
  The MCP stdio driver already exists as `go/cmd/mcp-n4/n4call`; scratch Python for a live check is now a kit gap.
