### Added

- build-n4-module: `toolbelt/plat-read.sh details|liststations|ipconfig` runs one read-only `plat` verb against a platform daemon over TLS, with the daemon credential read from a mode-0600 env file and masked in all output; verbs that change the host or a station are refused. plat exits 0 after a Java exception (a wrong password prints `AuthenticationException`), so `plat-read` exits 1 and names the failure (issue #850).
