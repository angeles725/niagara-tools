## What happened
The round-10 client sweep (kit issue #459) reported nine false-positive shapes. The four in Go rules on main were
fixed truth-first, each with a seeded golden or truth case from the real client code, and report-module now runs
the n4lint-ported lints it skipped. The rc-scan shapes and arbitrary-ord stay with their ports.

**The silent-protection premise of the issue was wrong.** The issue said a `*Alarm` status slot on the B-facade
(`dischargeHighAlarm` on BCompressorControl) "is never seen". It is: the surfaced-field index is tree-wide, so
`getDischargeHighAlarm().setValue(ctl.dischargeHigh)` in the facade already surfaces the pure class's
`if (dischargeHigh)` cap (live CompressorControl.java:982 was never a row). The row the issue cites,
CompressorControl.java:963 at 17c80d3, is a different line: `target = Math.min(target, available);`, an
unconditional capacity cap that counted as "on condition" only because an `if (c.minStagesOn > 0) { ... }` block
had closed within 10 lines above it. The fix is the guard scope (an `if` guards a trip only when the trip's action
lies inside that if statement), not a facade pairing; the facade pairing is now pinned by the same golden.

- catch-no-400: a catch whose only statement returns a call receiving the parse's own input
  (`return range.get(tag);`) re-reads the value, it substitutes no default. The rule proves the fallback is a
  function of the input; it cannot prove the second read rejects a bad value.
- null-context-write: an rt seed of the component's own child (receiver from `get(...)`, `new`,
  `TYPE.getInstance()` or `this`, no parameter value, in a file that serves no request) is no row. Doctrine
  reading: types/security.md §1.1 is the servlet/user-write hazard; a station-internal write has no user and null
  is the documented norm there (types/actions.md `fire(..., null)`, Slot-o-Matic setters).
- bql-string-concat: a concatenation whose every operand is a literal or a name of numeric/boolean type declared in
  the same method is no injection.
- report-module: 12 Go-ported lints wired (7 per artifact src, 1 -wb, 1 -ux rc, 3 module-root); the PASS detail no
  longer spells FAIL.
