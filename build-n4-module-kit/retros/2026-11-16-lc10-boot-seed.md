# 2026-11-16 · kit · lc10-boot-seed

**Session**: row P1 of a client A retro: a control cycle that runs before the persisted slots are seeded overwrites them at station boot.
**Delta count**: 1

## What happened
Client A's compressor control module ran its control cycle from `changed()` with no steady-state check. The cycle
mirrored the in-memory model's latches (auto-lockout, over-amperage) into persisted read-only slots, but the model
was loaded from those slots only in `atSteadyState()`. An input change between Component Start and steady state
therefore wrote the model's default `false`/0 over the saved latches, and the seed then read the defaults back: a
locked compressor could come back unlocked after a restart. The fix seeds at the top of the cycle and makes the
publish write nothing while unseeded; a lab stop-start kept the saved latch slots. A read-only audit of the client
modules afterwards found the same module still writing its run hours, rotation lead and config revision before
their own seeds, so the rule covers every persisted group a cycle writes, not only the one that failed.
