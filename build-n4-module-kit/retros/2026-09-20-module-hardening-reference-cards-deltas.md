## What happened
Seven reference-card blocks (B1106–B1112) completed the "REF cluster" — authoritative catalogs for BFacets keys, BStatus bits, BQL functions, BEnumRange grammar, SlotPath names, BRelTime encoding, and BFormat patterns. B1113 (RUN1) opened the failure-mode sub-series with the framework wrapper boundary: executeExtensions wraps each extension, but changed()/timer/lifecycle callbacks are bare. Our kit documents none of these. Five of the eight deltas are genuinely actionable for our modules (isValid status-check, SlotPath.escape for external names, BRelTime wire conversion, BFormat untrusted-input security, timer re-arm in finally); three are pure reference cards (BFacets key catalogue, BQL catalogue, BEnumRange grammar). This retro proposes; it does not edit the kit.

## Evidence
- B1106: complete BFacets key catalogue — 31 keys, including the 20+ that B49 omitted (radix, showSeconds, fieldWidth, showUnits, unitConversion, maxOverrideDuration, targetType, the 5 editor keys, etc.) plus factory-method catalog. `[ev: corpus B1106]`
- B1107: BStatus 8-bit reference + the isOk()==bits==0 vs isValid() distinction; isValid() is the correct gate for control math (alarm/override bits leave isOk() false but isValid() true). `[ev: corpus B1107]`
- B1108: BQL function catalogue — 5 aggregate functions (`BBqlLibrary` Type[] fields), 7 expression scalar functions (public static methods), 24 BBqlTime library functions (time/range helpers); reflective resolution means names are un-greppable; custom functions registered via a public static method on a BObject library class with `moduleSpec::fn()` call. `[ev: corpus B1108]`
- B1109: BEnumRange authoring grammar (`[frozen"+"]{pairs}[?opts]` BNF, BOG `E:` form), make() overload catalogue, and the non-contiguous-ordinal gotcha: `make(String[])` forces 0..n-1 ordinals; protocol enums with gaps need `make(int[], String[])`. `[ev: corpus B1109]`
- B1110: SlotPath slot-name grammar — first character must be alpha or `$`-escaped (NO leading digit or underscore); only `_` is unescaped in the identifier set; use `SlotPath.escape()` for names derived from external data (BACnet/meter names with spaces or leading digits fail silently otherwise); slot name ≠ display name — set them independently. `[ev: corpus B1110]`
- B1111: BRelTime wire/serialization encoding = `String.valueOf(millis)` (raw milliseconds), NOT ISO-8601; this is asymmetric with BAbsTime (`13,ISO-8601Z`); external clients (oBIX/REST/JSON) must be given an explicit conversion. `[ev: corpus B1111]`
- B1112: BFormat pattern language — `%script%` reflective calls, `.` chaining, `?` fallback, reflection resolution order, special-function lexicon (time, user, substring), FormatDenylist; a BFormat pattern with untrusted input is reflective code execution. `[ev: corpus B1112]`
- B1113: framework try/catch wrapper boundary — executeExtensions wraps each extension (SEVERE+continue), but changed()/timer callbacks/lifecycle callbacks are BARE; engine thread handler keeps the thread alive, but the invocation aborts; a self-rescheduling timer that throws before re-arm silently stops. `[ev: corpus B1113]`

## Lessons
- **Actionable for our modules (5):** Δ2 (isValid status-check), Δ5 (SlotPath.escape for external names), Δ6 (BRelTime wire conversion for oBIX/REST), Δ7 (BFormat security — never untrusted input), Δ8 (timer re-arm in finally). Each of these maps to a real failure mode in ColdRoomPan/CompPan/DashboardPan code paths and warrants a lint or explicit rule in the next campaign.
- **Pure reference cards (3):** Δ1 (BFacets key catalogue), Δ3 (BQL function catalogue + custom-fn how-to), Δ4 (BEnumRange grammar + non-contiguous-ordinal warning). Valuable as lookup material that replaces source-diving, but no immediate correctness risk in our current modules.
- The isOk() / isValid() distinction (Δ2) is the highest-priority actionable delta — confusing the two drops control output silently on alarm/override, exactly the fail-to-danger pattern B730/B650/B655 warned about.
- BFormat untrusted-input (Δ7) and the timer re-arm gap (Δ8) are the two least-obvious failure modes: no compile-time signal, no obvious runtime error — they rot state silently over time.
- The non-contiguous-ordinal gotcha in Δ4 is specifically relevant for protocol-enum slots where external hardware defines non-sequential ordinal codes (e.g. BACnet Multi-state objects, Modbus register values).
