## What happened
`toolbelt/rc-scan.sh` (464 lines: a two-pass gawk program per file plus a cross-file orphan-page awk) is now the
thin wrapper over `go/cmd/rc-scan` / `go/internal/rcscan`, header, usage, rows, exits and `# Mutation:` pins
kept. It is a command of its own, not an n4lint rule: its `<artifact-dir>`-first argument contract with
`--profile` / `--legacy`, its fixed `rc-scan` check column with a `<check-id>: ` message prefix and its
path-based walk fit no engine mode, and bending the engine would have cost four Spec fields for one tool. It
reuses the engine's walk (one new engine feature, its own green commit first: `lint.Selection` `Except`,
`Paths` and `PrunePaths`, the find `-not -name`, `-path` and `--prune-path` tests rc-scan passed to scan_files),
`lint.Finding.Row` and `rules/golden.Read`.

The port reads each file as gawk did under `LC_ALL=C`: awk records, bytes, POSIX classes and leftmost-longest
spans. A first cut was 8-15x slower than the awk on PANCCADIA and Umbrella (Go's linear NFA on 100-KB data-URI
and minified lines); every pattern now carries a literal its match must hold, a yes/no match runs leftmost-first,
and ord-literal, bare IPv4 and the login test are matched by hand (a differential test pins them to the EREs).

One declared difference in the port: an unreadable rc file is an env error (exit 3, `rc-scan: cannot scan <path>:
<reason>`). gawk printed its fatal line and the script went on, so the file's rows vanished and the scan could
pass clean (RS-unreadable).

Declared change outside the tool: `tests/go-wrapper-symlink.bats` stubbed `rc-scan.sh` as its "unrelated non-Go
member"; with rc-scan a Go wrapper, GWS2 failed (`rc-scan.sh(not-a-symlink)`). The test now stubs a dummy
`zz-plain-bash-member.sh` it creates in the copy, so it no longer depends on which real member is still bash.
