# 2026-10-24 · kit · go-rc-scan

**Delta count**: 3

## What happened
`toolbelt/rc-scan.sh` (464 lines: a two-pass gawk program per file plus a cross-file orphan-page awk) is now the
thin wrapper over `go/cmd/rc-scan` / `go/internal/rcscan`, header, usage, rows, exits and `# Mutation:` pins
kept. It is a command of its own, not an n4lint rule: its `<artifact-dir>`-first argument contract with
`--profile` / `--legacy`, its fixed `rc-scan` check column with a `<check-id>: ` message prefix and its
path-based walk fit no engine mode, and bending the engine would have cost four Spec fields for one tool. It
reuses the engine's walk (one new engine feature, its own green commit first: `lint.Selection` `Except`,
`Paths` and `PrunePaths`, the find `-not -name`, `-path` and `--prune-path` tests rc-scan passed to scan_files),
`lint.Finding.Row` and `rules/golden.Read`.

The port reads each file as gawk did under `LC_ALL=C`: awk records, bytes, POSIX classes and leftmost-longest
spans. A first cut was 8-15x slower than the awk on PANCCADIA and Umbrella (Go's linear NFA on 100-KB data-URI
and minified lines); every pattern now carries a literal its match must hold, a yes/no match runs leftmost-first,
and ord-literal, bare IPv4 and the login test are matched by hand (a differential test pins them to the EREs).

One declared difference in the port: an unreadable rc file is an env error (exit 3, `rc-scan: cannot scan <path>:
<reason>`). gawk printed its fatal line and the script went on, so the file's rows vanished and the scan could
pass clean (RS-unreadable).

Walk contract, checked after review (no difference to declare): lint.Walk prunes `*-worktrees` sub-directories,
follows a symlinked root and never prunes the root, even a dot-named one. The awk script did the same, because its
walk was `lib/scan-files.sh` (`prune=( -name '.*' -o -name '*-worktrees' )`, `find -H`, `-mindepth 1`); the awk and
the Go binary print the same rows for all three trees. These were unpinned for rc-scan; RS-walk pins them now (its
mutation, dropping the `*-worktrees` prune, was run and fails the pin).

Declared change outside the tool: `tests/go-wrapper-symlink.bats` stubbed `rc-scan.sh` as its "unrelated non-Go
member"; with rc-scan a Go wrapper, GWS2 failed (`rc-scan.sh(not-a-symlink)`). The test now stubs a dummy
`zz-plain-bash-member.sh` it creates in the copy, so it no longer depends on which real member is still bash.

Truth fixes after byte identity, for the four rc-scan shapes of kit issue #459, each one commit with the RED
observed first (a Go truth golden plus a bats pin named by a `# Mutation:` line):
- (d) `rc/vendor/**/*.js` is not scanned: lint-vendor-floor.sh owns vendored JavaScript (acorn at the Chromium 83
  floor, types/frontend-standard.md § Vendored libraries); vendored CSS/HTML stay scanned, `*.min.js` was already
  excluded. browser-floor is unchanged: § Profiles defines `unknown` as "rc-scan.sh browser-floor stays WARN", and the
  202 chihuahua / 105 ford rows are the modules' own CSS, not vendored code (RC33).
- (b) disabled-gate: a control the line disables while setting its own `.title` to a string literal naming no gate
  states a non-gate reason and is no row; a gate title, a non-literal or other element's title, a call receiver,
  setAttribute or a markup attribute keep it (RC34).
- (a) innerhtml-server, in two steps: the flagged line is decided on each sink's own value (jssrc tokens; a member
  elsewhere on a minified line, `Math.*`, `.length`, `.toFixed(` are no row, RC35), then a member of a const
  array/object literal the page declares, read through a lexically bound name (jssrc.Bindings: iterator callbacks,
  for-of, `.find(`, `[i]`, a const arrow returning `.find(`), is no row unless the page writes into that field or
  push()es into the literal (RC36).
- (c) host-literal stays FAIL, no code change: `base: "http://127.0.0.1/obix/..."` beside `mode: "json"` (PANCCADIA
  index.html:779) is dead only until someone edits one word of the shipped config, and then the HMI fetches a fixed
  plain-http host; proving a mode unselected needs evaluating the page. The client fix is a relative base
  (`/obix/config/...`), which the station resolves; recorded in the rc-scan.sh header.

New shared code: jssrc `Match`, `Expr`, template `Subs`, `Bindings` / `Lookup`, each with its own tests.

## Lessons
- Go's regexp is linear but not fast: a port of an awk lint over minified web assets needs literal pre-checks
  before the engine, measured on the real trees, not only on fixtures.
