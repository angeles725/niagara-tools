## What happened
Two findings the register did not carry. First, the X-Frame-Options default has two readings: the guide and
`BWebService.xFrameOptions` say `Sameorigin`, but the `BXFrameOptionsHeaderProvider` class default is `deny`; which
one a station shows depends on how its provider was created, so the kit now says to read the live value. Second,
downgrading `lint-servlet.sh api-response-headers` from WARN to INFO broke a consumer silently:
`report-module.sh` only parses `FAIL*|WARN*` rows, so a servlet whose only row was the INFO one reported
"SKIP no BWebServlet".

- `web-rt/…/javax/baja/web/http/BXFrameOptionsHeaderProvider.java:34` (`deny`), `web-rt/…/javax/baja/web/BWebService.java:255` (`sameorigin`), guide `User/web-HttpHeaderProviders.txt:20` ("defaults to Sameorigin") `[ev: corpus B1349 C1]`
