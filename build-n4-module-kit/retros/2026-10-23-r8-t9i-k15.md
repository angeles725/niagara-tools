## What happened
The old K15 read "Found multiple metadata blocks" literally and blamed a source with NO generated region. The
code throws that message whenever the region's stamp-line count is not exactly one, so the real trigger is the
opposite case: pre-written EMPTY markers (zero stamp lines). An exception message named for one case can be
raised for another; the kit rule has to state the code's condition, not paraphrase the message.
