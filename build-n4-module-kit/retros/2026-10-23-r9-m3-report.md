## What happened
`toolbelt/report-module.sh` had grown to 1610 lines. Most of that was one member-row parser pasted about 25 times:
`n = split($0, a, /[[:space:]]{2,}/)`, then status, check, site and reason, then the basename of the site path.
Every paste ran `printf '%s' "$_ln" | awk`, which forks awk once for each output row. The copies had also drifted
into five shapes: site (`basename:line  reason`), swap (lint-wb-threading prints `check  ST`), base (no `:line`
split; uberjar, bundled-jar), nosite (jasmine drops the site) and the whitespace-split verify-module / plano rows.
Now one awk program, `ROW_AWK`, runs once over a member's whole output, through `member_rows`. Two helpers wrap
it: `lint_rows` gives the common exit-3 / relay / `clean` verdict shape, and `have_src` gives the `no src/` SKIP
gate. The script is now 882 lines.

The architect asked for a table of member lints driving one generic runner. A table cannot keep the INDEX.md
Auto column. gen-lint-index marks a lint Auto only when a non-comment line of report-module.sh invokes
`"$TOOLBELT/<lint>.sh"` in command position. A generic `"$TOOLBELT/$tool.sh"` would turn every Auto cell to
"no". So each member keeps a two-line call site: the literal invocation, then `lint_rows`. This also keeps the
per-lint invocations that unit M3b will batch into one `n4lint` call.

Byte identity was kept on purpose, including degenerate input. The shell still splits each record on its first
two `|` characters, so a `|` inside a field is cut exactly as before. The swap-mode WARN filter compares the
status up to its first `|`, which is what the old shell `case` saw. The FAIL-only members keep the old rule that
any relayed row blocks `clean`, even `FAILx`. config-sanity and lint-structure block only on an exact `FAIL`.
lint-timers keeps `basename(1)` for the inputs where `${p##*/}` differs: empty, a trailing `/`, or a leading `-`,
where basename prints an invalid-option error.

## Lessons
- A generated index that reads call sites is a constraint on refactoring. Keep the literal invocation and share
  everything after it.
- Byte identity on degenerate input is cheap to keep: replay the old shell split on the new records instead of
  "fixing" it in awk.
- A stub toolbelt that prints one hostile corpus from every member exercises all parser paths in seconds. Real
  trees exercise almost none of the edge cases.
