## Lessons
- An approved review's advisories are new work; without an explicit limit, fixing them breeds the next round.
- Every stricter heuristic is a new way to miss a real shape; pin the old positives before narrowing.
- A shell replacement or a bats `!` can silently do nothing; quote replacements and assert exit codes.
- On an unknown START outcome, the lineage STATUS is the only source of truth.
- An advisory list stored as lens/severity/location only can be re-derived from the reviewed PR head, but it costs a
  full re-read; keep the finding text with the location when posting.
