## What happened
Five units, one goal: a kit tool never reports green on input it did not read.

1. `awk_lint_run` passed the file path with `awk -v FILE=`, which escape-processes the value, so a path
   holding `\t` printed a tab in every row. FILE now comes from `ENVIRON["AL_FILE"]` in a BEGIN prelude
   run ahead of `AL_AWK_ARGS` and main.awk, as `awk_lint_each` already did. `[ev: retro go-lint-ord-ports Δ1]`
2. `.githooks/pre-push` counted only `build-n4-module-kit/**` and `scripts/**` as build-relevant. The
   toolbelt wrappers exec Go binaries now, so `go/**` (except the built `go/bin/`) joins the set.
   `[ev: retro go-javasrc-scanner Δ1]`
3. `toolbelt/host-budget.sh` is the toolbelt entry point of `go/cmd/host-budget` (canonical Go-wrapper
   shape, real-path `here=`); BUILD-LOOP §7 Shared host points the pids and disk reads to it.
   `[ev: retro r8-t47-host-budget Δ1]`
4. lint-servlet, slot-coverage per-slot and verify-module --src kept private `find | sort` walkers read
   through a process substitution: find's exit status was lost, so an unreadable sub-directory was skipped
   and the module passed; none pruned `*-worktrees`. They now walk through `lib/scan-files.sh`. verify-module
   runs `java_files` inside process substitutions, so the walk error is recorded in a file under its temp
   dir and the run exits 3 with an INCOMPLETE verdict after printing its rows.
5. On an EMPTY root 26 of the bash lints exited 0 with no output (the five that already returned 3 had
   each hand-written the same check). The rule now lives once: `_al_list` in lib/awk-lint.sh and the new
   `scan_files_nonempty_or_exit` in lib/scan-files.sh print `ERROR  <name>  <root>  no files to scan
   (K20: wrong path or empty scaffold)` and exit 3. A mistyped root that does not exist already exited 3
   everywhere; the silent case was a real directory with nothing the lint scans.

## Lessons
- A walk that lists nothing is input the tool did not read, exactly like a walk that could not enter a
  directory; both belong in the one shared lister, not in each lint.
- A helper run in a process substitution cannot set the caller's variables: record its failure in a file.
- A test title and its assertion can disagree for months (LRP-smoke); read both when a fix flips one.
