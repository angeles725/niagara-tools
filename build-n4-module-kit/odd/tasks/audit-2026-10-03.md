## Objective
Fix what a read-only audit of the kit (on 255f2d9) found: lints and gates that can report a clean pass on a real
defect, the `report-module.sh` / `ng-deploy.sh` floor that can pass with skipped checks, ledger-sweep blind spots,
skill and doc drift, CI gaps, and four field-incident lint candidates. Fold the deferred-lints close retro first and
close with release v0.32.0.

## Problem / why
- The deferred-lints close retro is `pending`; its five deltas live only in the retro.
- 12 lints still walk with `find … 2>/dev/null`: a sub-directory `find` cannot enter is skipped and the lint reports
  the module clean — the #226 lead class, which the previous feature fixed in six other lints only.
- Several checks can pass on a real defect (timer-ticket `cancel` token anywhere, mixed-unit time compare, a javac
  failure reported as a test failure) and the report/deploy floor can read CLEAN with a non-skippable check skipped.
- The ledger sweep misses malformed marker structure; the skill and BUILD-LOOP name paths and counts that drifted.
